# Font assets

`baloo.json.gz` is the Baloo font, converted to gzip-compressed JSON for the
`gmlewis/fonts` toolchain. Baloo is licensed under the SIL Open Font License,
Version 1.1. Copyright and license terms are those of the Baloo project
(https://github.com/EkType/Baloo).

The font data is vendored unchanged from the reference repository and is used
only by the examples and the text feature.
