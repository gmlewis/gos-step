# API reference

The public facade is `step` (`src/lib.gos`). Types are re-exported with
`pub type` aliases; constructors and terminals are free functions so they read
well in a `|>` pipeline.

## Types

```gos
pub type Design = ...
pub type Shape = ...
pub type SceneNode = ...
pub type Rgb = ...
pub type Face = ...
pub type Profile = ...
pub type BezierPath = ...
pub type BezierAnchor = ...
pub type SweepPath = ...
pub type SweepProfile = ...
pub type Font = ...
pub type Repository = ...
pub type Error = ...
pub type V2 = (f64, f64)
pub type V3 = (f64, f64, f64)
```

## Colours

`ORANGE`, `BLUE`, `GREY`, `PURPLE`, `MAGENTA`, `WHITE`, `BLACK`, `GREEN`,
`RED`, `CYAN`.

## Shape / SceneNode / Design methods

```gos
impl Shape {
    named(self, name) -> SceneNode
    colored(self, color) -> SceneNode
}
impl SceneNode {
    named, colored
    moved(self, x = 0, y = 0, z = 0) -> SceneNode
    turned_x/y/z(self, degrees) -> SceneNode
    repeat_at(self, locations: Vec<V3>) -> Vec<SceneNode>
    bounding_box(self) -> Bounds
}
impl Design {
    add(self, node) -> Design
    add_all(self, nodes) -> Design
    documented(self, text) -> Design
    moved(self, x = 0, y = 0, z = 0) -> Design
    turned_x/y/z(self, degrees) -> Design
    compile(self) -> Repository
    to_step(self) -> String
    write_step(self, path: Option<String>) -> Result<(), Error>
    to_blender(self, keep_modifiers = false) -> String
    write_blender(self, path, keep_modifiers = false) -> Result<(), Error>
}
```

## Compatibility aliases

The original API is available through the same core: `Cuboid::new`,
`CalibrationChamferBlock::new`, `ExtrudedProfile::new`,
`ExtrudedBezierProfile::new`, `SweptProfile::new`, `Shape::with_name`,
`Shape::with_color`, `SceneNode::with_name/with_color/translate/rotate_x/y/z`,
`union_all`, `difference`.
